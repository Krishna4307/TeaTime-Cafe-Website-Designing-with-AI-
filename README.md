#project Name :  TeaTime Café
# Overview of Project : 
  A responsive coffee and tea shop website for a fictional café in Madhapur, Hyderabad. Built with plain HTML, CSS and vanilla JavaScript, 
  with no frameworks or   build tools. It works like a real café site: customers can filter the menu, add items to a cart and change quantities.

# Feautures of the Project
  -Menu filter: show All, Hot Coffee, Cold Coffee & Drinks, Tea, or Snacks & Desserts
  -Shopping cart: add items, increase or decrease quantity, remove items, live item count in the navbar and a running total
  -Saved cart: cart is stored in localStorage, so it stays after a page refresh
  -Special offers: combo and evening deals, which can also be added to the cart
  -8 pages in one site: Home, About, Menu, Offers, Gallery, Contact, Login/Register, Cart (hash-based routing, no page reloads)
  -Responsive design: works on mobile, tablet and desktop, with a collapsible mobile navbar
  -Light and dark theme: follows the visitor's system setting
  -Accessibility basics: keyboard focus styles, ARIA labels, reduced-motion support
  -Customer reviews, newsletter form, and café facilities sections on the home page
  
# Techonologies Used
  -HTML 5
  -CSS 3
  -Vanilla Javascript (ES6)
